## Projetos em destaque

### FisioApp: Plataforma de gestão clínica com IA

Plataforma de gestão clínica voltada à fisioterapia, com funcionalidades para gerenciamento de pacientes, anamnese, evolução dos atendimentos, patologias e protocolos de exercícios.

O projeto também conta com um simulador de pacientes virtuais utilizando Inteligência Artificial, permitindo que profissionais pratiquem o raciocínio clínico em diferentes cenários e níveis de dificuldade.

**Destaques técnicos:**
- Desenvolvimento de APIs com Django REST Framework.
- Integração com OpenAI e arquitetura extensível para múltiplos provedores de LLM.
- Abstração de provedores utilizando `Python Protocol`, com contratos padronizados e implementações independentes.
- Gerenciamento de contexto, histórico de conversas e consumo de tokens.
- Estratégias de segurança para proteção contra Prompt Injection.
- Testes automatizados e tratamento de exceções em fluxos generativos.

[Repositório do FisioApp](https://github.com/danieldonizeti/fisio-app)

### Task Manager API: Gerenciamento de tarefas

API REST desenvolvida com Django REST Framework, com foco em organização, segurança, modelagem e qualidade de código.

**Principais implementações:**
- Autenticação e autorização com JWT.
- CRUD de tarefas e gerenciamento de categorias.
- Isolamento de dados por usuário.
- Filtros e paginação.
- PostgreSQL e Docker.
- Testes automatizados com pytest e pytest-django.

### Sistema de Recomendação Machine Learning e Busca Vetorial

Projeto desenvolvido durante os estudos em Engenharia de IA, utilizando um dataset real obtido no Kaggle.

O trabalho envolveu processamento e preparação dos dados com Python e Pandas, treinamento de um modelo com TensorFlow.js e armazenamento de representações vetoriais utilizando PostgreSQL e pgvector.

A recomendação é realizada por meio da recuperação dos itens com maior similaridade em relação ao vetor de representação do usuário.

**Conceitos e tecnologias explorados:**
- Preparação e limpeza de dados com Pandas.
- Treinamento de modelo com TensorFlow.js.
- Representação de dados por embeddings.
- Armazenamento vetorial com PostgreSQL e pgvector.
- Busca por similaridade e recomendação de itens.
